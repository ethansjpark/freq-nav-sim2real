## Core Constraints

- This project is a controlled scientific study, not a performance optimization task.
- Existing source files must not be modified unless explicitly stated.
- Environment setup must be additive-only (new files/scripts/docs).
- No reward shaping, PPO architecture changes, or evaluation definition changes.
- Visual frequency manipulation is the primary independent variable.

## AI Usage Rules

- Editor mode is used for explanation and small, scoped edits.
- Agents may only be used for additive setup or explicitly bounded tasks.
- Any agent task must specify goal, constraints, boundaries, and verification.
